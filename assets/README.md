각각 같은 이름의 `.jpg` 는 영상 로딩 전 포스터입니다.

## 처리 내역

원본 23MB → **8.6MB**. 1920×1080 / 25fps / H.264 / CRF 27–28 / faststart,
**오디오 트랙 제거**(muted 여야 자동재생됩니다). 색보정은 CSS `filter` 로 처리하므로
교체할 때는 **원본 그대로** 넣으시면 됩니다.

## 교체할 때

- 16:9, 1920×1080 이상, 6–12초, 앞뒤가 이어지는 루프
- 각 5MB 이하
- 카메라 고정. 팬·줌이 들어가면 광고처럼 보입니다
