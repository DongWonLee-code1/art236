| 파일 | 쓰이는 곳 |
|---|---|
| `hero-1.mp4` ~ `hero-5.mp4` | 히어로 캐러셀. `hero-1`=쌓인 캔버스, `hero-2`=붓과 먼지, `hero-3`=작업 책상, `tab-canvas`=물감 클로즈업, `tab-artist`=작업 중인 작가 |
